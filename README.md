# NIP rent

Aplikacja do rozliczania najmowanych mieszkań.

## Getting started

- Używając *Python3.12* utwórz *venv* i zainstaluj zależności

```sh
python3.12 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
Edytowanie plików bezpośrednio na GitHubie jest szybkim sposobem na wprowadzenie drobnych zmian. Po zatwierdzeniu zmian, zobaczysz nowy commit w historii projektu. Porada programistyczna: Nie jest dobrą praktyką wprowadzanie jakichkolwiek zmian bezpośrednio na gałęzi 'main', ponieważ może to prowadzić do problemów z synchronizacją i potencjalnych konfliktów. Zawsze lepiej jest tworzyć nową gałąź, wprowadzać zmiany tam, a następnie łączyć je z 'main' za pomocą Pull Requesta (PR). Jednakże, dla celów tej lekcji (w szczególności pracy indywidualnej), edycja bezpośrednio na 'main' jest dopuszczalna, aby pokazać proces synchronizacji zmian.
